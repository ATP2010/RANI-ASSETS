RANI Actions

memeriksa native host…
  1. Pasang rani-action-host.exe (installer dari admin RANI).
  2. Buka edge://extensions / chrome://extensions → klik ikon puzzle → detail ekstensi RANI → Izinkan.
  3. Klik tombol Actions di halaman Assets RANI.
Ekstensi hanya aktif di halaman web RANI (halaman bertanda <meta name="rani" content="app">).
