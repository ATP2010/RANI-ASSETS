Pakai yang -signed (disarankan). Kalau Windows tetap memblokir, pakai raniPush-portable.zip. Sertifikat publik + script pemasangannya ada di daftar atas untuk PC yang memblokir “Unknown publisher”.
Pasang di PC Windows — tanpa token
  1. Download raniPush-signed.exe (tombol di atas).
  2. PowerShell as Admin: Unblock-File .\raniPush-signed.exe
  3. Kirim inventaris sekali untuk tes: 
    .\raniPush-signed.exe {{ server_url | replace('http://', '') | replace('https://', '') }}
    Exit code 0 = data masuk. Cek di /assets dan tabel agent di halaman ini.
  4. Jadwalkan tiap jam: 
    schtasks /create /tn RaniPush /sc hourly /ru SYSTEM /rl HIGHEST /f /tr "C:\Rani\raniPush-signed.exe {{ server_url | replace('http://', '') | replace('https://', '') }}"
  5. Log: C:\ProgramData\Rani\raniPush.log. Panduan lengkap: docs/agent-windows.md.
Agent dikenali dari machine_id PC — tidak ada token, tidak ada langkah enroll. Siapa pun yang bisa menjangkau port ini bisa mengirim inventaris; kalau itu tidak diinginkan, set RANI_TOKENLESS_PUSH=0 di .env lalu semua agent wajib pakai token + HMAC.
