Cara pasang raniPush (tanpa token)
  1. Unduh {{ exe.name }} dari panel kanan (jalur B), atau {{ portable.name }} (jalur A) kalau Windows memblokir exe. Simpan ke C:\Rani\.
  2. PowerShell as Administrator: 
    cd C:\Rani
Unblock-File .\{{ exe.name }}
.\{{ exe.name }} {{ server_url | replace('http://', '') | replace('https://', '') }}
    Exit code 0 = data terkirim (atau terspool bila server belum terjangkau). Server mengenali PC dari machine_id, jadi tidak ada langkah enroll.
  3. Cek hasilnya: aset muncul di /assets dengan badge online, dan baris agent baru muncul di tabel bawah halaman ini (badge direct).
  4. Jadwalkan tiap jam (SYSTEM, tanpa jendela): 
    schtasks /create /tn RaniPush /sc hourly /ru SYSTEM /rl HIGHEST /f ^
  /tr "C:\Rani\{{ exe.name }} {{ server_url | replace('http://', '') | replace('https://', '') }}"
  5. Log ada di C:\ProgramData\Rani\raniPush.log: 
    Get-Content C:\ProgramData\Rani\raniPush.log -Tail 20
  6. Troubleshooting cepat: 401 = agent di-revoke atau server memakai RANI_TOKENLESS_PUSH=0; 422 = payload ditolak skema (kirim output --collect); koneksi ditolak = cek Test-NetConnection ke port {{ server_port }}.
